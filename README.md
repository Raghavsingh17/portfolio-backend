# 🚀 Raghav's Portfolio Backend API

Backend REST API service for Raghav Singh's Portfolio, built with Node.js, Express, TypeScript, MongoDB, and Google Gemini AI.

---

## ⚡ Quick Start

### 1. Install Dependencies

```bash
npm install
```

### 2. Start Development Server

```bash
npm run dev
```

### 3. Build & Start Production

```bash
npm run build
npm start
```
